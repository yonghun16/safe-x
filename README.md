## 📖 프로젝트 개요

![project_period](https://img.shields.io/badge/Project-2026-FF6B00)

**Safe-X**는 건설 현장의 위험 요소를 쉽고 빠르게 제보할 수 있도록 제작한 모바일 안전 관리 애플리케이션입니다.

현장에서 발견한 위험 요소를 사진과 함께 등록하면 다른 작업자들도 즉시 확인할 수 있으며, 위험도를 기준으로 우선순위를 파악하여 안전사고를 예방할 수 있습니다.

또한 검색 기능을 통해 특정 지역이나 키워드의 제보를 쉽게 찾아볼 수 있으며, 사용자별 게시글 관리 기능도 제공합니다.

# ✨ 주요 기능

## 🏠 홈

- 최신순 / 인기순 제보 조회
- 위험도(낮음 / 보통 / 높음) 표시
- 좋아요 및 댓글 확인
- 최근 등록된 위험 요소 확인

---

## 📸 위험 요소 제보

사용자는 현장에서 발견한 위험 요소를 즉시 등록할 수 있습니다.

### 등록 항목

- 사진 업로드
- 제목
- 상세 내용
- 위험 위치
- 위험도 선택

---

## 🔍 검색

원하는 위험 요소를 빠르게 검색할 수 있습니다.

### 검색 기능

- 키워드 검색
- 최근 검색어 저장
- 추천 지역 제공
- 검색 결과 조회

---

## 👤 마이페이지

사용자 정보를 관리하고 작성한 게시글을 확인할 수 있습니다.

### 제공 기능

- 프로필 조회
- 내가 작성한 게시글
- 저장한 게시글
- 알림
- 설정
- 로그아웃
